# 測試問題集

| 分類 | 測試問題 | 驗收重點 |
|---|---|---|
| 課程資訊 | 114 年第 01 期是什麼課程？ | 回答期別、課名、時數、來源 |
| 課程資訊 | 115 年第 02 期課程重點有哪些？ | 回答生成式 AI、大數據、影像辨識等 |
| 報名資格 | 失業者可以報名嗎？ | 不保證資格，提醒官方審核 |
| 補助費用 | 15-29 歲青年一定可以領 8000 嗎？ | 不得保證，一律說符合資格者可申請 |
| 甄試資訊 | 114 年第 01 期甄試日期？ | 回答知識庫明確日期 |
| 報名方式 | 要去哪裡報名？ | 提供台灣就業通或官方平台方向 |
| 聯絡方式 | 洽詢電話是多少？ | 回答 06-213-0019 或 06-2130019 |
| 在職訓練 | 在職勞工補助去哪查？ | 導向在職訓練網 |
| 無資料 | 請告訴我錄取標準 | 無明確資料時不得編造 |
