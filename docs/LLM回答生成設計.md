# LLM 回答生成設計

## 目標

在保留 RAG 檢索、來源依據與防幻覺規則的前提下，加入可選的 LLM 回答生成。

## 啟用條件

需同時設定：

- `OPENAI_API_KEY`
- `LLM_MODEL`

若未設定，系統使用本機模板回答。

## 流程

1. 使用者提問
2. 問題分類
3. Hybrid RAG 檢索
4. 取得相關 chunk 與來源標籤
5. 若 LLM 已啟用，將問題、分類、來源與 chunk 組合成 prompt
6. LLM 產生繁體中文客服回答
7. 若 LLM 失敗，退回本機模板回答
8. 儲存問答紀錄與是否使用 LLM

## 防幻覺規則

Prompt 中明確要求：

- 只能根據知識庫內容回答
- 不可自行編造日期、金額、名額、課程代碼、甄試題型或錄取標準
- 補助只能說「符合資格者可申請」
- 不可保證錄取
- 不可混用 114/115 期別
- 不可混用職前/在職訓練
- 知識庫不足時需說明無明確資料

## API 狀態

`GET /api/knowledge/status` 會回傳：

- `llm_enabled`

`POST /api/chat` 會回傳：

- `llm_used`
