# 系統架構規劃

## 系統定位

本系統定位為「基於 RAG 的 AI 智慧客服與課程報名輔助平台」，不是單純聊天機器人。系統需結合知識庫檢索、來源引用、FAQ、申請流程導覽、補助資格說明、後台知識庫管理與使用者回饋。

## 文字架構圖

使用者瀏覽器  
↓  
前端網站 Frontend  
↓  
後端 API Server  
↓  
RAG 問答服務  
↓  
文件資料庫與向量資料庫  
↓  
大語言模型 LLM  
↓  
回答生成與來源引用  
↓  
回傳答案給使用者

## 第一階段實作範圍

- 前端先提供單頁問答介面
- 後端先提供 `/api/chat`、`/api/knowledge/status`
- RAG 先使用本機 TXT 與簡易關鍵字檢索
- 回答先提供摘要方向、引用 chunk 與注意事項
- 第二階段再接正式 LLM 與向量資料庫

## 重要限制

- 不可保證補助資格
- 不可保證錄取
- 不可保證最新梯次資訊仍有效
- 不可混用 114 年第 01 期與 115 年第 02 期資訊
- 不可混用職前訓練與在職訓練規則
