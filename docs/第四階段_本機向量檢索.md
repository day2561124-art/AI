# 第四階段：本機 Hybrid 向量檢索

## 目標

第四階段的目標是將第一、二階段的關鍵字檢索，升級為可展示 RAG 概念的本機 hybrid 檢索流程。

此階段暫不依賴外部 API、不需要 OpenAI API key，也不需要資料庫服務即可執行。

## 已完成能力

- 保留關鍵字檢索
- 新增 TF-IDF 本機向量化
- 使用 cosine similarity 計算問題與 chunk 的相似度
- 合併關鍵字分數與向量分數
- 保留 metadata 過濾
- 保留 114/115 期別分流
- 保留職前/在職訓練分流
- 回傳來源依據時保留分數資訊供後端除錯

## 為什麼先做本機向量檢索

本機 TF-IDF 不是正式 Embedding，但適合專題展示：

- 不需要付費 API
- 不需要網路
- 可以說明 RAG 的檢索、排序、來源引用流程
- 未來可替換為 OpenAI Embedding 或 pgvector

## 下一步可升級

正式版可替換為：

- OpenAI Embeddings
- Supabase pgvector
- Pinecone
- Weaviate

替換重點在 retriever，不需要大改前端或 API。
